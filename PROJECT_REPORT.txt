1. INTRODUCTION
--------------------------------------------------------------------------------
In Electrical, Electronics, and Telecommunication Engineering, "Signals and
Systems" forms the foundational bedrock for subsequent fields such as Digital
Signal Processing (DSP), Control Systems, Telecommunications, and Analog/Digital
Circuit Design. 

At the center of this domain is the concept of a "System" — a physical or 
mathematical entity that accepts an excitation input signal x(t) and transforms 
it into a response output signal y(t) according to a governing operator T{·}:
                          x(t) ───► [ System T{·} ] ───► y(t)

Traditionally, academic curricula teach the classification of systems through
abstract algebraic proofs and static textbook equations. Students often struggle
to correlate theoretical definitions with the physical, observable behavior of
signals in real-world engineering instruments.

The "System Properties Verification Virtual Lab" is an interactive, browser-based
educational workbench designed to solve this educational bottleneck. Modeled after
modern digital bench oscilloscopes and high-precision signal generators, it gives
students a hands-on environment where they can synthesize continuous-time signals,
tune electrical parameters in real-time, observe running live oscilloscope beams,
and verify the five fundamental system properties:
  1. Linearity vs Non-linearity
  2. Causality vs Non-causality
  3. Time-Invariance vs Time-Variance
  4. BIBO Stability vs Instability
  5. Static (Memoryless) vs Dynamic (With Memory)

2. OBJECTIVES
--------------------------------------------------------------------------------
The primary aims and objectives of this Virtual Laboratory are:

1. Bridge Theory and Practice:
   Transform abstract mathematical concepts of superposition, temporal causality,
   time shifts, bounded envelopes, and memory into intuitive, visual phenomena.

2. Interactive Virtual Instrumentation:
   Provide an intuitive software function generator and digital oscilloscope
   that runs in real time at 60 frames per second directly in the browser.

3. Systematic Property Verification:
   Deliver dedicated experimental verification sections for all five core
   properties, comparing nominal signal responses against non-linear, non-causal,
   time-variant, unbounded, and memory-dependent counterparts.

4. Minimalist Cognitive Design:
   Eliminate distracting equation walls, unnecessary quizzes, and complex menus
   in favor of a clean, light/white laboratory interface focused purely on
   signals, waveforms, and direct feedback.

5. Universal Accessibility:
   Ensure the lab runs out-of-the-box on any standard web browser without
   requiring proprietary software licenses (such as MATLAB or LabVIEW), plugins,
   or physical laboratory hardware.

3. MODULES
--------------------------------------------------------------------------------
The architecture of the Virtual Lab is organized into six cohesive modules:

• MODULE 1: Navigation & View Controller Module
  - Provides a clean, top-level segmented switch between the two primary
    workspaces: "Theory" and "Experiment".
  - Manages seamless state transitions and handles dynamic resizing of the
    embedded plotting engines when toggling between views.

• MODULE 2: Theory & Conceptual Foundation Module
  - Presents five student-friendly concept cards explaining each property in
    plain language with concrete examples and mathematical tests.
  - Concludes with a direct "Go to Experiment" action button that guides students
    directly into the practical workbench.

• MODULE 3: Virtual Function Generator (Input Signal Synthesis Module)
  - Located in the left lead panel (width ~310px).
  - Offers a dropdown selector featuring 7 continuous-time signal types:
      * Sine Wave        : A·sin(2πft + φ)
      * Cosine Wave      : A·cos(2πft + φ)
      * Square Wave      : A·sgn(sin(2πft + φ))
      * Triangular Wave  : (2A/π)·arcsin(sin(2πft + φ))
      * Unit Step        : A·u(t)
      * Ramp Signal      : A·r(t)
      * Exponential      : A·e^(-at)·u(t)
  - Interactive parameter controls:
      * Amplitude (A)    : Range 0.2 V to 3.0 V (Step: 0.1 V)
      * Frequency (f)    : Range 0.2 Hz to 4.0 Hz (Step: 0.1 Hz)
      * Phase (φ)        : Range -3.14 rad to +3.14 rad (Step: 0.1 rad)

• MODULE 4: Real-Time Oscilloscope Visualizer Module
  - Displays a high-contrast primary scope screen dedicated to the input signal x(t).
  - Employs a continuous live animation engine that propels the waveform across
    the time grid at 60 FPS, mimicking a hardware digital phosphor oscilloscope.
  - Features a live pulsing status pill ("[ ● LIVE RUNNING ]" / "[ PAUSED ]").

• MODULE 5: Signal Metrics & Measurement Engine
  - Real-time digital multimeter/counter readout displaying:
      * Peak-to-Peak Voltage (V_pp = 2A)
      * Fundamental Period (T = 1/f)
      * Angular Frequency (ω = 2πf)

• MODULE 6: System Properties Verification Module (5 Rectangular Sections)
  Organized as five stacked horizontal rectangular cards in the main display:
  
  a) Linearity Section:
     - Tests the Superposition Principle: T{a·x₁ + b·x₂} = a·y₁ + b·y₂.
     - Compares the active signal x(t), a linear scaled output 2x(t), and
       a non-linear distorted output x²(t) on a shared live rectangular plot.
  
  b) Causality Section:
     - Tests temporal dependency: y(t) must depend only on x(τ) for τ ≤ t.
     - Compares present signal x(t), a causal delayed sample x(t - 0.5), and
       a non-causal future sample x(t + 0.5) against the probe instant t = 0.
  
  c) Time-Invariance Section:
     - Tests clock-independence: T{x(t - t₀)} = y(t - t₀).
     - Displays the original wave x(t) and its time-delayed counterpart
       x(t - 1.0s) propagating in synchronous alignment.
  
  d) BIBO Stability Section:
     - Tests bounded output under bounded input: |x(t)| ≤ M_x < ∞ => |y(t)| ≤ M_y < ∞.
     - Visually maps the live signal x(t) between upper (+M_x) and lower (-M_x)
       finite limit bounds.
  
  e) Static / Dynamic (Memory) Section:
     - Tests memory requirements: static systems require only the current instant x(t),
       whereas dynamic systems store energy or require past/future memory buffers.
     - Displays an instantaneous sampling cursor at t = 0 alongside an
       accumulating memory buffer trace.

4. TECHNOLOGY USED
--------------------------------------------------------------------------------
The laboratory is developed using standard, lightweight web technologies:

1. HTML5 (HyperText Markup Language 5):
   - Semantic document structure (<header>, <main>, <aside>, <section>).
   - Clean accessibility markup (ARIA roles, labeled range inputs, live regions).

2. CSS3 (Cascading Style Sheets 3):
   - Custom CSS Design Tokens (:root variables for consistent palette control).
   - Modern layout frameworks: CSS Flexbox and CSS Grid.
   - Clean, glare-free White / Light Laboratory Theme.
   - Subtle hardware-inspired elevations, smooth hover micro-animations,
     and pulsing live indicators.

3. JavaScript (ECMAScript 2022 / ES6+):
   - Pure client-side object-oriented architecture (App, Plots, Signals, Systems).
   - Zero framework overhead (Vanilla JavaScript ensures instant loading).
   - Real-time numerical signal generation and sample interpolation.

4. Plotly.js (Hardware-Accelerated Visualization):
   - High-performance vector plotting library.
   - Utilizes low-overhead restyle operations (`Plotly.restyle`) to update
     waveforms in microseconds without triggering heavy browser layout reflows.

5. HTML5 RequestAnimationFrame API:
   - Synchronizes mathematical signal synthesis with the browser monitor's
     refresh rate (60 FPS) for buttery-smooth live beam propagation.

6. Node.js (Development & Local Hosting):
   - Lightweight local web server environment (`server.js`) for zero-dependency
     local hosting.

5. KEY FEATURES
--------------------------------------------------------------------------------
• Live Running Oscilloscope Beam:
  Waveforms continuously stream in real time across the screen, providing an
  authentic laboratory oscilloscope experience.

• Interactive Live Parameter Tuning:
  Sliders for Amplitude, Frequency, and Phase dynamically alter the running
  wave without requiring a page reload or calculation restart.

• Full-Width Rectangular Property Sections:
  Each property is housed in an ergonomic rectangular panel with a dual-column
  layout: conceptual takeaways on the left and live verification graphs on the right.

• Single Clean Input Scope:
  Eliminates dual-channel confusion by displaying a single, focused, full-width
  input signal scope at the top of the workbench.

• Run / Pause & Instant Reset:
  Allows students to pause the live beam at any instant to inspect sample values,
  or reset all sliders to standard laboratory defaults with a single click.

• Glare-Free White Theme:
  Designed with a clean, modern white aesthetic (#ffffff / #f8fafc) featuring
  crisp typography and high-contrast trace colors (#0284c7, #16a34a, #d97706).

• Ultra-Fast Client-Side Execution:
  All computations execute locally in the client browser, ensuring zero server
  latency and complete privacy.

6. ADVANTAGES
--------------------------------------------------------------------------------
1. Active Experiential Learning:
   Students learn by manipulating signals and observing outcomes directly,
   yielding significantly higher concept retention than static diagrams.

2. Zero Installation / Platform Independence:
   Operates on Windows, macOS, Linux, ChromeOS, and mobile browsers without
   installing heavy software suites or compiling code.

3. Cost & Resource Free:
   Eliminates the need for expensive physical function generators and digital
   storage oscilloscopes (DSOs), democratizing access for institutions with
   limited hardware lab budgets.

4. Safe Experimentation:
   Students can freely explore high frequencies, extreme amplitude swings,
   and unstable conditions without risk of damaging physical equipment or
   causing circuit burnouts.

5. Distraction-Free Pedagogy:
   Avoids gamified clutter or complex mathematical notation walls, focusing
   cleanly on the signal properties required by university syllabi.

7. FUTURE SCOPE
--------------------------------------------------------------------------------
The architecture of this Virtual Lab is designed for modular expansion:

1. Discrete-Time (DT) Signals & Systems:
   Extend the verification engine to include discrete sequences x[n] and
   difference equations y[n] using impulse stem plots.

2. Web Audio API Integration:
   Synthesize audible acoustic outputs from the generated waveforms, enabling
   students to hear the difference between a pure sine wave (linear) and a
   clipped square wave (non-linear harmonics).

3. Custom Mathematical Formula Input:
   Incorporate an interactive math expression parser allowing users to type
   arbitrary equations such as y(t) = tanh(x(t)) or y(t) = x(3t - 2).

4. Frequency Domain & FFT Spectrum Analyzer:
   Integrate a live Fast Fourier Transform (FFT) spectrum analyzer displaying
   the harmonic frequency content of the signal alongside the time domain.

5. Automated Assessment & Lab Report Generator:
   Enable students to generate and download signed PDF experiment reports
   containing timestamps, configuration values, and captured waveform screenshots.

8. CONCLUSION
--------------------------------------------------------------------------------
The "System Properties Verification Virtual Lab" successfully bridges the gap
between abstract mathematical signal theory and intuitive visual experimentation.
By providing a live, 60 FPS running oscilloscope visualizer, interactive parameter
controls, a distraction-free white laboratory interface, and five dedicated
rectangular property verification sections, the lab transforms complex engineering
concepts into an engaging, accessible, and self-directed learning experience.

Whether deployed as an interactive visual companion during university lectures,
utilized in distance education programs, or explored by independent engineering
students, this virtual laboratory serves as a robust, modern, and cost-effective
tool for mastering the fundamental properties of Signals and Systems.
