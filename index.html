Understanding System Properties

In signals and systems, a system transforms an input signal x(t) into an output signal y(t) = T{x(t)}. Systems are categorized according to five fundamental properties that determine their physical behavior. Review the intuitive explanations below, then click the button to verify them experimentally.

1. Linear vs Non-linear

A system is linear if it obeys the principle of superposition (scaling and additivity): scaling the input scales the output proportionally, and adding two inputs adds their outputs.

If doubling the input doubles the output, the system is linear. If powers (such as x²(t)), cross-terms, or constant offsets exist, it is non-linear.

Linear: y(t) = 2x(t),   y(t) = dx/dt
Non-linear: y(t) = x²(t),   y(t) = 2x(t) + 3

2. Causal vs Non-causal

A system is causal if the output at any instant t depends strictly on present or past values of the input (t′ ≤ t). It never anticipates the future.

Physical real-time systems are always causal because future events cannot be known in advance. If y(t) requires x(t + 1), the system is non-causal.

Causal: y(t) = 2x(t),   y(t) = x(t − 1)
Non-causal: y(t) = x(t + 1),   y(t) = x(2t) (for t > 0)

3. Time-Invariant vs Time-Variant

A system is time-invariant if a time delay in the input signal produces an identical delay in the output signal, without altering its waveform shape.

In short: the system does not change its characteristics over time. If explicit time coefficients appear (like t · x(t)), it is time-variant.

Time-Invariant: y(t) = 2x(t),   y(t) = x(t − 1)
Time-Variant: y(t) = t · x(t),   y(t) = x(2t)

4. Stable vs Unstable (BIBO)

A system is BIBO Stable (Bounded-Input Bounded-Output) if every bounded (finite) input signal produces a strictly bounded (finite) output signal.

If a bounded input causes the output amplitude to grow indefinitely or diverge to infinity, the system is unstable.

Stable: y(t) = 2x(t),   y(t) = |x(t)|
Unstable: y(t) = ∫ x(τ) dτ (step input creates ramp)

5. Static vs Dynamic (Memory)

A system is static (memoryless) if its output at any instant t depends solely on the input value at that exact same instant t.

A system is dynamic (with memory) if it stores energy (like capacitors/inductors) or requires past or future values (delays, derivatives, or integrals).

Static: y(t) = 2x(t),   y(t) = x²(t)
Dynamic: y(t) = x(t − 1),   y(t) = ∫ x(τ) dτ

1. Linear / Non-linear ● Linear

Linear systems satisfy superposition: scaling and addition of signals produces proportional response without non-linear distortion.

2. Causal / Non-causal ● Causal

Causal systems depend strictly on present and past signal values (t ≤ now). Non-causal systems anticipate future values.

Dependency: Present & Past Samples Only
3. Time-Invariant / Variant ● Time-Invariant

Time Shift: T{x(t − t₀)} = y(t − t₀)
