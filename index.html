What are System Properties? (Understood in 2 Minutes!)

Don't let complex Greek equations intimidate you! In Electronics, a system is simply a black box that transforms an input into an output: Input $x(t) \longrightarrow \boxed{\text{System } T} \longrightarrow \text{Output } y(t)$.

Rule 1

Linearity

"The Fair Multiplier & Fair Addition Rule"

If you double the input, does the output double? If you feed two signals $(A + B)$ at the same time, is the result just $(Output_A + Output_B)$?

$$T\{a x_1 + b x_2\} = a T\{x_1\} + b T\{x_2\}$$
💡 Example: $y(t) = 2x(t)$ is linear. But $y(t) = x^2(t)$ is non-linear because doubling the input quadruples the output!
Rule 2

Time-Invariance

"The Clock Doesn't Matter Rule"

If you play your favorite song now vs 10 minutes later, does it sound the same? Yes! A time-invariant system gives the exact same shape, just delayed by the same amount.

$$T\{x(t - t_0)\} = y(t - t_0)$$
💡 Example: $y(t) = x(t - 2)$ is time-invariant. But $y(t) = t \cdot x(t)$ is time-varying because the multiplier $t$ changes as time passes!
Rule 3

Causality

"No Time-Traveling Rule"

Can your radio play tomorrow's news today? No! A real-world system only reacts to what happened in the past or right now. It can never depend on future inputs.

$$y(t) \text{ depends only on } x(\tau) \text{ for } \tau \le t$$
💡 Example: Delay $x(t - 2)$ is causal (past). But advance $x(t + 2)$ is non-causal because at $t=0$ it requires input at future instant $t=2$!
Rule 4

BIBO Stability

"Don't Blow Up Rule"

If you give the system a normal, bounded input signal (like volume within $\pm 1$), does the output stay bounded, or does it explode to infinity and blow up your speakers?

$$|x(t)| \le M_x < \infty \implies |y(t)| \le M_y < \infty$$
💡 Example: Scaling $2x(t)$ is stable. But an Integrator $\int_{-\infty}^t u(\tau)d\tau$ on a constant step produces an ever-growing ramp $t \to \infty$ (Unstable)!
